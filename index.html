第 1 章 木材切削的基本概念 Basic concepts

切削与木材切削的定义

切削 cutting：刀具相对工件按预定轨迹运动，切除一部分工件材料或使之分离，使加工部位或工件获得一定精度之尺寸、形状、表面质量。

木材切削 wood cutting：借助刀具，按预定的表面，切开工件上木材之间的联系，从而获得符合要求尺寸、形状和表面粗糙度的制品，这种工艺过程称为木材切削。

切削三要素 考点

机床 Machine、刀具 Tools、工件 Workpiece 三者构成三角形关系：机床提供动力和运动、夹持刀具和工件；刀具是切削工具；工件是加工对象。

切削运动与切削用量 Cutting motion & parameters

主运动与切削运动

主运动 primary motion：从工件上切除切屑、形成新表面所需要的最基本运动。

v = πDn / (6×10⁴) D—刀具（或主锯轮）直径 mm；n—转速 r/min；v—m/s

切削运动 cutting motion：主运动与进给运动同时进行时产生的相对运动，V' = V + U（矢量和）。一般主运动速度远大于进给速度，常用主运动速度的大小方向代表切削运动速度。

常见运动组合：一个直线运动（刨削、刮削）；两个直线运动（带锯、排锯）；一个回转 + 一个直线（铣削、钻削）；两个回转运动（仿型铣削）。

切削用量三要素 考点

  • 切削速度 V：常以主运动速度表示；
  • 进给量 f：每齿进给量 fz 或每转进给量 f；
  • 背吃刀量 as（切削深度 h）：待加工表面与已加工表面之间的距离。
其大小表明切削强度高低，影响生产率、加工质量、动力消耗和刀具磨损。任何切削机床设计都必须首先确定切削用量；任何切削作业都必须先设定切削用量。

刀具几何角度 Tool geometry

刀具的几何表面与切削刃

刀具切削部分简化为一楔形体：前刀面（切屑流过的表面）、后刀面（与加工表面相对的表面）、侧面（与前面、后面相邻的面）；主刃＝前面与后面的交线，侧刃＝前面与侧面的交线。

坐标平面与测量平面

  • 切削平面 cutting plane：通过切削刃与加工表面相切的平面；即主运动速度与切削刃组成的平面。主运动为直线且切削刃为直线时与已加工表面重合；回转运动时位置随刃口位置改变。
  • 基面：通过主切削刃上某一点并与该点切削速度方向相垂直的平面。
  • 正交平面（法向剖面）：通过主切削刃上某一点并与主切削刃在基面上投影相垂直的平面。

四个基本角度 考点

  • 前角 γ rake angle：在正交平面（法向剖面）内度量的前刀面与基面间夹角；
  • 后角 α clearance angle：法向剖面内度量的刀齿后面与切削平面间夹角；
  • 楔角 β sharpness angle：前、后刀面之夹角；
  • 切削角 δ cutting angle：前刀面与切削平面之夹角。
γ + α + β = 90°　；　δ = α + β　；　δ + γ = 90°

工作角度 ≠ 标注角度

实际切削中刀具角度因切削运动、刃安装高度、磨损等而改变。因进给运动存在，相对运动速度与主运动间有夹角 αm = arctan(U/V)，切削平面旋转 αm，工作后角 αw = α − αm。αm 远小于 1°，通常用标注后角代替工作后角；仅当主运动与进给速度相差较小时才需考虑工作角度。

切削层尺寸参数 Chip geometry

切削层与切削厚度 考点

切削层：刀具相对工件沿进给方向每移动一个每齿进给量 Uz（或每转进给量 Un、每双行程进给量 Ustr）后，一个刀齿正切削的木材层。

切削厚度 a：相邻两切削轨迹间的垂直距离。主运动为直线运动时为常数；回转运动时在切削过程中变化：

a = Uz · sin(θ) θ—运动遇角，即切削速度与进给速度间的夹角

切削深度、宽度与面积

  • 切削深度 h：已加工表面与待加工表面间的垂直距离；
  • 切削宽度 b：刀刃与工件间的接触长度；
  • 切削面积 A = a·b（mm²）；回转运动时随切削厚度变化。

切削方向 Cutting directions 重点考点

二维切削与三维切削 考点

  • 二维切削：直角自由切削——仅一个垂直于切削速度方向的刀刃参与切削，刀刃与切削方向垂直，切屑在横向无变形；
  • 三维切削：刀刃与切削方向存在倾斜角，切屑在垂直于切削方向上有变形。

按切削速度方向与纤维方向的关系分：三个基本方向（纵向、横向、端向）＋三个过渡方向（纵端向、纵横向、横端向）。

三向切削的定义 考点·会画图

名称代号定义
纵向切削[90-0]刀刃与木材纤维方向垂直，切削速度平行于纤维方向
横向切削[0-90]刀刃与纤维方向平行，切削速度垂直于纤维方向
端向切削[90-90]刀刃和切削速度均与纤维方向垂直

三个角度：纤维倾角、纤维交角、年轮接触角 考点

  • 纤维倾角（动力遇角）φ：平行于切削方向且垂直于切削平面的平面内，切削方向与纤维方向的夹角；
  • 纤维交角：切削平面内，切削方向与纤维方向的夹角；
  • 年轮接触角：垂直于切削方向和切削平面的平面内，切削平面与年轮切线间的夹角。
顺逆纹分界：纤维倾角 0~90° 为顺纹切削，90~180° 为逆纹切削；纤维交角为 90° 时即横向切削。

木材切削的特点 Characteristics

各向异性 考点

木材的特点：各向异性、不均匀性、强度低；易变形、压缩、开裂、起毛；不耐热，易焦化或炭化。

影响切削的木材特性：含水率、密度、强度、组织结构、切削方向、温度。

高速切削与楔角 考点

  • 切削速度 40~70 m/s，最高 120 m/s；刀轴转速 3000~12000 r/min，最高 24000 r/min，可获得较高几何精度和表面粗糙度；
  • 温度高（500℃ 左右甚至更高）；噪声很大需降噪；高速回转部件需静、动平衡；机床需抗振性好；刀具材料与结构需适应高速切削。
  • 刀具楔角小：木材强度低、易变形，分离木材所需力占比大；楔角小、刀具锐利，利于切屑与工件分离。
  • 切屑可能也是加工产品。

第 2 章 切屑形态 Chip types

木材切削层在刀具作用下发生剪切、挤压、弯折等变形而与工件分离形成切屑。

切削方向切屑类型别名/特征
纵向纵Ⅰ型屑瓣间界线有时分明（多角形），有时不清（螺旋状）＝折断型
纵向纵Ⅱ型光滑螺旋型＝流线型
纵向纵Ⅲ型压碎、皱折＝压缩型
横向横Ⅰ型屑瓣间界线清晰，屑瓣稀松相连
横向横Ⅲ型屑瓣间界线不明
横向横Ⅰ-Ⅲ过渡型—
端向端Ⅰ型剪切型
端向端Ⅱ型撕裂型

流线型切屑（纵Ⅱ型）考点

条件：纵向切削时切削角和切削深度较小。过程：刀具切入时 Fy 较小、切削层薄、无劈裂，切削层在前刀面推挤下连续剪切破坏，生成连续带状屑片。特点：①切削力稳定、无明显周期；②切屑连续带状、切削质量好；③功耗大、刀刃磨损快。

剪切型切屑（端Ⅰ型）

条件：纤维倾角较大时的顺纹切削（纵-端向切削）。过程：刃口切入，前刀面木材被压缩，受平行纤维方向的剪切力发生剪切滑移，随刃口前移压缩-剪切滑移以一定间隔断续发生。特点：切屑较连续、切削力均匀、质量较高。

撕裂型切屑（端Ⅱ型）考点

条件：刃口不锐利的端向切削，或逆纹纵向切削，切削角和切削深度较大。过程：刃口前移给纤维横向拉力，刃口下方木材沿纤维方向开裂；同时前刀面压缩切削层使其弯曲或剪切破坏。特点：切削质量差、切屑无规则、切削力变化较大。

超前劈裂 考点

顺纹切削超前劈裂小 → 加工面光洁；逆纹切削超前劈裂大 → 加工面粗糙。

切削表面质量与加工精度 Surface quality

表面质量评价与缺陷原因 考点

评价方法：①良好面百分率；②缺陷种类及频率；③表面粗糙度（常用，粗糙度仪测量）；④实际生产多用肉眼判定。

缺陷产生原因：①加工机械与刀具设计本身不合理；②机械、刀具调整不当、参数不合理、磨损；③材料纹理结构、材质不均。

改进横向切削质量的措施 考点

  1. 蒸煮木材：软化并增加韧性，减少开裂；
  2. 刃前加压尺：防止超前开裂，并挤出一部分水分（减少干燥时间和动力消耗）；
  3. 加大刃倾角：改横向切削为纵横向切削。

加工精度 考点

尺寸精度：实际加工尺寸与预定目标尺寸的符合程度；形位精度：实际形状、位置与预定目标形位的符合程度。

影响因素：①加工机械精度（调整、结构、振动）；②刀具性能（材质、刚度、磨损、刃口缺损）；③加工参数（刀具参数、切削参数）；④木材材性（切削性质、密度、内应力、力学性能）。

切削热与刀具温度 Cutting heat

刀具升温的后果与热传导

刃口温度上升加速磨损；刀体温度分布不均使刀具丧失稳定性；已加工表面炭化、焦化。热传导：刀齿与工件接触摩擦生热 → 齿尖升温并向刀体传导 → 向环境辐射散热。车削、钻削为连续切削；铣削、锯切为断续切削。

刀具温度的影响因素

  • 刀具材料：导热系数、前后刀面粗糙度、材料种类与质地；
  • 刀具参数：切削角（楔角）、后角、锐利程度（刃圆半径）；
  • 切削参数：切削速度、切削厚度；
  • 切削方式（封闭、半封闭、自由；参与切削刃口数）；
  • 周围环境（气温、风速）。

工件切削面温度

刀刃温度可达 500℃，甚至 1000℃ 以上；切屑和已加工面也接近刀刃温度。工件温度随切削速度增加而升高；切削力随温度升高而降低。木材易热分解；切削慢或停止进给时灼烧，降低表面质量并缩短刀具寿命。

第 3 章 切削力与切削应力 Cutting forces

切削力与切削阻力 考点

切削应变：切削层木材、切屑和切削平面以下木材在刀具作用下发生弹性、塑性变形的结果。

切削力：对被切削工件而言，是将切削层木材从工件上分离并排出所需的作用力；切削阻力：对刀具而言，是切削力的反作用力。

切削应力分布（9 种）

  1. 刃口处集中应力；2. 前刀面摩擦应力；3. 切屑弯曲压应力；4. 切屑弯曲拉应力；5. 切削方向压/拉应力；6. 垂直于切削方向的剪应力；7. 大切削角时的压缩剪应力；8. 端向切削时木纤维弯曲应力；9. 端向切削时作用于木纤维的拉应力。

主切削力、法向力与临界切削角 考点

  • 主切削力 Fyx：通常为正值，与 δ 大小无关；
  • 法向力 Fyy：δ 较小为正（前刀面推压切屑使其分离弯曲）；δ 较大为负（切屑挤压刀具压向切削表面）；Fyy 正负还受刃圆半径影响；
  • 临界切削角：法向力 Fyy = 0 时的切削角。
  • 斜刃切削（λ≠0）：多一个横向分力 Fyz；Fyx 比 Fyy、Fyz 大得多，后两者约为主切削力的 1/3。

切削阻力 Cutting resistance 考点

切削力反作用力＝切削阻力；切削阻力容易测得，是评价材料切削性能的基础。

影响因素三组

①被切削工件性质（树种、密度、含水率、温度、力学性能）；②刀具参数（切削角、后角、刃倾角）；③切削条件（切削深度、切削方向、切削速度）。

工件性质的影响

  • 密度：随密度增大切削阻力线性增加，端向增加更明显；
  • 含水率：随含水率降低，切削阻力在纤维饱和点后增加，约 10% 时最大，低于 10% 变化不明显或略降；
  • 温度：随温度升高呈下降趋势；力学强度越高阻力越大。

刀具参数的影响

  • 切削角：随 δ 增大，纵向切屑由流线型→折断型→压缩型，端向由剪切型→撕裂型，阻力增加；
  • 刃倾角（0~60°）：端向水平分力基本不变（略降）；纵向阻力降低；横向先降后升。

切削深度的影响

深度增加 → 截面积增大 → 切屑由折断型向压缩型变化 → 阻力增大；此时增大切削角阻力增加更显著（试验：糖松，含水率 8%，切削宽度 6.4 mm）。

第 4 章 锯与锯切加工 Sawing

锯切定义与锯子种类 考点

锯切：利用锯子截断、剖分工件的过程。锯子种类：无端带形（带锯条）、条形（框锯）、圆形（圆锯片）；由锯齿和锯身组成。

纵锯齿的切削过程 考点

进给方向平行于纤维方向（剖料）。三个刃口（主刃端向切削 + 侧刃横向切削）每行程完成三个切削面：锯路底 + 两侧锯路壁。

过程：主刃先端向切削切断锯路底纤维；前齿面使切断木材剪切破坏；侧刃清理锯路壁；锯屑暂存齿室，锯齿离开木材时排出。

δ 的影响：δ < 90° 先切底、后裂壁；δ > 90° 先切壁、后切底。

横锯齿的切削过程 考点

进给方向（锯路方向）垂直于纤维平面；选用 δ > 90° 的斜磨拨料锯。锯齿如小刀切出刀痕，相邻锯齿先后切出两条平行刀痕；前齿面合力在垂直锯路方向的分力 F3 挤压两侧已切开木材，使其沿锯路底顺纤维方向剪切破坏形成锯屑（剪应力超过顺纹抗剪极限）。

侧刃作近于端向切削；主刃作横端向切削；侧刃担负主要切削任务。

锯齿的种类与构形 Saw teeth

锯齿分类与参数 考点

按锯切相对纤维方向：纵剖齿、横截齿；按刃磨方式：直磨齿、斜磨齿。主要尺寸：齿距 t、齿高 h；主要角度：前角 γ、后角 α、楔角 β；锯料：锯料宽 B、锯料角 λ。纵剖直磨齿为正前角，横截斜磨齿为负前角；锯料分拨料与压料。

带锯锯切定义 考点

带锯锯切：带锯机是以封闭无端的带锯条张紧在回转的两个锯轮上，使其沿一个方向连续匀速运动，从而实现锯切木材的机床。

带锯齿形 考点

  • 直背齿：锐度、强度、排屑能力均要求中等的场合；
  • 曲背齿：后齿背弧形凸起，抗弯强度高；但锐度小、排屑不易、后角小；适宜粗加工和大带锯剖料；
  • 凹背齿：齿尖锐利、排屑好；强度低；适宜锯切较软的木材。

其他齿形：截背齿、浅矮齿、长矮齿、双斜齿。

齿室：形状应保证锯屑畅行；前齿面、齿腹、齿底、后齿面交接处平滑；齿底圆弧半径 R ≈ 0.15t；齿室容积等于或略大于齿体体积。

带锯条受力（6 种应力）考点

  1. 张紧应力 σ₁：σ₁ = F / [(B−h)·s]（MPa）；
  2. 弯曲应力 σw：σw = E·s / [(1−μ²)·D]（MPa）；
  3. 切削应力：锯齿侧压应力、锯背拉应力；一般工作载荷锯齿侧 12 MPa、锯背 14 MPa；重载 15 / 18 MPa；
  4. 锯轮前倾应力：约 5 MPa；
  5. 热应力 σt：σt = E·α / (ti − t)（MPa）；
  6. 离心应力 σc：σc = ρv² / g（MPa）。
叠加结果：有齿边反而不如锯背拉得紧，对锯切不利。因此需用滚压适张，事先给锯条预应力，抵消切削热、锯轮倾斜、切削力等造成的负效应。

张紧与跑锯 考点

关键：锯齿侧锯身部分在锯切中要张得足够紧。

跑锯原因：①锯齿部分抵抗进给力的能力总比锯身中部弱；②锯切中锯齿部分发热伸长大于其他部分，张紧力降低；③应力叠加后锯齿侧松弛、锯背应力大。

解决办法：①增大张紧力（受抗拉强度限制）；②加厚锯齿部分（制造使用有问题）；③使锯条预先获得适当张紧度（适张度）。

带锯条的适张处理 Tensioning 考点

解决锯齿工作稳定性最常用、最经济、最行之有效的方法：辊压锯身。辊压在锯身内引入预应力，使锯齿侧预先具有适当张紧度；辊压是辊子压力下锯身产生弹性变形和塑性变形的过程。

三种辊压方法对比 考点·哪种最好

  1. 辊弯势法：最大辊压力在锯背，锯背塑性变形最大；但张紧后锯齿部分增大的预张应力仍不足以补偿其应力下降；
  2. 辊圆势法：锯身中部施加大辊压力，张紧后两侧张紧应力大于中部；锯齿部分预张应力仍不足；
  3. 辊弯势 + 圆势法（最好）：中部和背部同时重压，使锯齿侧适张应力最小；张紧后锯齿部分张紧应力足够大，弥补应力下降。

辊压后锯背部分或中部长度比锯齿侧大；张紧后达到 “齿紧、腰松、背弓”。

第 8 章 刀具磨损与耐用度 Tool wear

磨损分类与正常磨损特点 考点

刀具磨损：切削时刀具材料逐渐损失，刀具形状相对原始形状的变化。

  • 异常磨损：刀尖折断、崩刃、刃部塑性变形、卷刃、掉齿 → 不合格产品；
  • 正常磨损：切削部分材料逐渐损耗，微观几何形状变化。特点：①前后刀面同时磨损，前刀面可能出现月牙洼；②以后刀面磨损为主，磨损量大于前刀面，刃口呈圆弧形，钝圆半径逐渐增大。

磨损原因

  • 机械磨损：材料迁移、擦伤；
  • 热磨损：成分扩散变劣；前面与切屑粘结；热应力龟裂、表层脱落；冷热变化热疲劳；切削热与阻力引起塑性变形钝化；
  • 化学磨损：刀具材料与木材成分反应；硬质合金 Co、WC、TiC 高温氧化生成疏松氧化物被擦伤带走；
  • 电化学磨损、电腐蚀磨损：电化学反应；电火花放电（适当施加负电荷可减小磨损）。

影响耐用度的因素 考点

  • 被切削材料：端向切削比纵向、横向更易使刃口变钝；内含物、pH 值影响明显；三聚氰胺对刃口磨损最严重；砂质、硅含量提高 → 耐用度下降；
  • 加工条件：切削速度 V↑、进给速度 Vf↑、切削深度 as↑ → 耐用度下降。

刀具耐磨损技术

  1. 表面热处理：淬火 + 回火提高表面硬度；
  2. 表面渗碳、渗氮、渗硼，提高耐磨耐腐蚀性；
  3. 表面镀铬：保护刀体、降低摩擦系数；
  4. 热喷涂：喷涂金属、合金、金属陶瓷、氧化物、碳化物；
  5. 涂层技术：CVD、PVD、PECVD 镀涂 TiN、TiC 等，适用于硬质合金刀齿。

磨削加工特点（补充） Grinding

  1. 每个磨粒的切削刃极不规则；
  2. 磨粒在磨具表面分布很不规则，切削量很不均匀；
  3. 磨削表面发热、温度很高；
  4. 磨削所需的切削能量大。
